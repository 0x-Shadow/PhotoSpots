# PhotoSpot Map Repair & UI Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair the basemap (CARTO now watermarks every anonymous tile), make location permissions grantable and repairable, and redesign the navigation, motion, update prompt, settings, spot detail and add-a-place flow onto one design system.

**Architecture:** The existing provider + repository structure is kept. New isolated units are added: `lib/map/tile_sources.dart` (basemap registry + probe/fallback), `lib/services/geocoding.dart` (Photon search/reverse), `lib/theme/app_typography.dart` (type roles), `lib/widgets/update_sheet.dart` and `lib/screens/settings_screen.dart` (single implementations of duplicated UI). Screens are migrated onto `AppTypography`/`AppColors`/`AppMotion` in place; no router or folder restructure.

**Tech Stack:** Flutter 3.47.7 (Dart ^3.13.5), flutter_map ^8.3.2, latlong2, provider, geolocator ^14.1.2, shared_preferences, http ^1.2.2, **share_plus (new)**. Free/keyless services only: Esri Dark Gray canvas, OpenStreetMap, Photon (komoot).

**Spec:** `docs/superpowers/specs/2026-11-26-redesign-design.md`

## Global Constraints

- Free stack only: no paid service, no API key required for the default experience.
- Default basemap must be keyless dark (`dark` style); `carto` is opt-in only with a stored key.
- Aesthetic bar: Apple-level restraint; the amber-glow interactive accent does not survive — interactive accent is `#0A84FF`, amber `#FFA94D` is removed from `AppColors.accent`/`accentSoft` and star colour `#FFB84D` stays ratings-only.
- No inline `fontFamily: 'Inter'` outside `lib/theme/*` after Task 4 (audited in Task 10).
- Touch targets ≥44dp (`AppLayout.minTapTarget` = 48), text contrast maintained, all motion honours `MediaQuery.disableAnimations`.
- `flutter analyze` must be clean (no new infos), `flutter test` green, `flutter build web --release` succeeds.
- Flutter binary: `/home/nick/flutter/bin/flutter` (not on PATH).
- Brand string is "PhotoSpot"; remove stray "findr." and "p." references when touching those lines.
- Commands run from `/home/nick/Documents/projects/locations`.

## Review Focus

Input/failure modes the spec implies but no happy-path task exercises — each has a test below.

1. **CARTO watermark tiles** (HTTP 200, valid PNG, wrong content) — a probe that only checks status would pass. Test: Task 1 `probe classifies the known watermark digest as unavailable`.
2. **Permission denied forever / services off** — the current dead end. Test: Task 3 `classify maps deniedForever to blocked and disabled services to servicesOff`, plus widget test that the recovery sheet offers an *Open settings* action.
3. **Photon unreachable (offline /429 / malformed JSON)** — must never block publishing. Test: Task 8 `search returns an empty list when the client fails or the body is not a list`.
4. **Add flow with no GPS fix** — must not silently pin Lisbon. Test: Task 8 `initial pin prefers the cached fix and falls back to the map centre`, and city falls back to a manual field.
5. **Update install permission missing on Android** — the `needsPermission` phase must still render with its action. Test: Task 6 `update sheet renders the install-permission explanation with an action`.
